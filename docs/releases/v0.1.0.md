# v0.1.0 — iPPLab 预览版

这是 Idea Inbox 的第一个公开二进制预览版：安卓随手记，Windows 接着整理。记录保存在本机，通过配对后的局域网 HTTPS 手动双向同步。

## 下载与安装

- `idea-inbox-v0.1.0-windows-x64.zip`：解压到可写目录，运行其中的 idea_inbox.exe。保持 DLL、data 和 licenses 目录完整，不要只复制 exe。Windows 10/11 x64；首次联网需允许可信专用网络。如提示缺少 Microsoft Visual C++ 运行库，从 [Microsoft 官方页面](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)安装 x64 运行库。本包未使用 Windows 代码签名，不要求关闭系统防护。
- `idea-inbox-v0.1.0-android.apk`：通用正式签名 APK，Android 7.0+，包含 arm64-v8a、armeabi-v7a、x86_64；使用长期 iPPLab 项目签名。自行下载侧载时按系统提示操作，不关闭 Play Protect 等防护。
- `idea-inbox-v0.1.0-notices.zip`：第三方许可与运行时通知；随 APK 再分发时一起保留。
- `SHA256SUMS.txt`：下载后使用 `Get-FileHash <文件名> -Algorithm SHA256` 比对完整性。

版本号 0.1.0+1，安卓包名 dev.ideainbox.idea_inbox。

## 从此前的 debug 包迁移

正式签名与此前 debug 签名不同，不能直接覆盖安装。请先在旧应用内导出 JSON 完整备份并确认备份文件已保存到应用之外，再卸载旧包、安装正式包并合并恢复备份。卸载会删除应用本机数据；不要先卸载再找备份。恢复不包含设备密钥或配对状态，需要重新配对。

以后更新正式包应保留相同签名和包名，并增加 versionCode。不要用调试签名或重新生成的密钥冒充连续更新。

## 本版功能和边界

- 纯文字离线记录、搜索、归档、回收站和恢复。
- 一部安卓手机与一台 Windows 电脑，二维码配对，电脑确认，证书指纹固定，前台手动双向同步。
- 不可变修订、重复传输去重、保留并发冲突并手动合并。
- JSON 备份恢复、Markdown 导出。
- 没有笔记云端或账号后端。**安卓扫码使用 Google ML Kit，其 SDK 收集诊断和使用指标；本版不声称整包零遥测。** 详见 [Google 官方披露](https://developers.google.com/ml-kit/android-data-disclosure)。扫码模型随包提供。
- 无附件、USB、自动发现或后台同步；仅支持私有 IPv4 局域网。
- 每条最多 32000 个 UTF-16 code units、10000 个修订、单次同步消息 16 MiB、备份恢复 64 MiB，尚未分页。
- 笔记和导出文件没有应用层静态加密；同步不能替代独立备份。

## 签名维护（维护者）

构建脚本仅从以下环境变量读取签名：IDEA_INBOX_KEYSTORE、IDEA_INBOX_KEY_ALIAS、IDEA_INBOX_STORE_PASSWORD、IDEA_INBOX_KEY_PASSWORD。缺少变量时 release 任务明确失败，不退回 debug 签名。配置这些变量后执行：

```powershell
flutter build apk --release --no-pub
```

本次签名密钥和加密口令保存在维护者机器的仓库外目录，未提交 Git，未包含在发布附件。DPAPI 口令文件绑定当前 Windows 用户/环境，单独拷贝该文件不能保证在另一台机器恢复。

**请尽快将密钥以及可恢复的口令分别备份到可信离线介质或密码管理器。不要在聊天、Issue 或仓库中粘贴口令。不要删除密钥；丢失后无法按当前签名正常更新已有安装。** 当前目录本身不构成异地备份。
